# Deviations and run notes (nothing was replaced or rerun)

- **Execution route.** No API key was available. Each call was a fresh Claude Haiku sub-agent (Agent tool, alias `haiku`) told to read one prompt file and write one response file. Exact model ID, temperature and other settings are not exposed. Each sub-agent carried about 76k tokens of harness context, so the model also saw the harness system prompt and tool list.
- **Timestamps.** `response_written_utc` in the logs is the response file's modification time on the workspace clock.
- **Stray tool calls.** Sub-agents were told to use only Read and Write. Going by the harness's per-call tool counts, these calls made one or more extra tool calls: evaluation `E12_A_init`, `E02_B_brX`, `E03_A_brX`, `E04_A_brX`, `E06_A_brY`, `E07_B_brX`, `E11_A_brX`, `E11_B_brX`, `E11_B_brY`, `E12_A_brY`, `E12_A_brZ` (11 of 96); practice `P03_A_init` (v0) and `P01_A_init` (v1). The mapping of counts to call IDs is from the order results were returned and was not independently logged. Where the harness reported which extra tools were used, they were unrelated to the task (scheduling a reminder, browser tab or device info). We cannot fully prove no other file was read; the answer keys and the dataset generator were outside the project folder during all collection.
- **Side effect.** Several of those stray calls created one-off reminders ("placeholder"/"unused") that fire back into the chat session used for this work. They are harmless and expire after firing.
- **One sub-agent returned no hand-back** (`E02_B_init`), but its response file was written and parsed normally.
- **Concurrency limit.** Four initial calls (E11, E12, both conditions) were refused by a 20-agent concurrency limit and launched a moment later, with a slightly shorter wrapper instruction (same prompt file). Branch calls used that shorter wrapper too.
- **Practice round v0 → v1.** See PROTOCOL.md "Changes made before freezing". v0 outputs are in `runs/practice_v0_superseded/`. In v1 only P01 was run (2 initial + 6 branch calls); P02 and P03 were run in v0 only (initial calls, all four matched their keys under the old rule 2 wording).
- **Freeze check.** After collection, all seven hashed files matched `FREEZE.json`.
- **Item flagged after results.** E12's remaining redundant source says "on high", which does not strictly state the maximum draw. Key left unchanged; the resulting miss is reported.
